# 🛒 お買い物リストアプリ

HTML・CSS・JavaScript を用いて作成した、  
**スマートフォン対応のお買い物リストアプリ**です。

GitHub Pages を利用して公開しており、  
iPhoneでは「ホーム画面に追加」することで  
ネイティブアプリのように使用できます。

---

## 📱 主な機能

- 複数のお買い物リストを作成  
  - 日付
  - お店の名前
- 商品ごとの管理
  - 商品名の追加
  - 価格の入力
  - チェックボックスによる購入完了管理
  - 個別削除（確認ダイアログあり）
- リストごとの管理
  - 合計金額の自動計算
  - リスト全体の削除（確認ダイアログあり）
- スマートフォン・PC 両対応（レスポンシブデザイン）
- オフライン対応（localStorage を使用）

---

## 💻 使用技術

- HTML5
- CSS3（Flexbox）
- JavaScript（ES6）
- Web Storage API（localStorage）
- GitHub Pages（公開）

## 📲 iPhoneでの使い方

1. Safariで上記URLを開く  
2. 画面下の「共有」ボタンをタップ  
3. 「ホーム画面に追加」を選択  
4. ホーム画面のアイコンから起動

※ App Store は不要です。

---

## ⚠️ 注意点

- データは **端末ごとに保存** されます  
- 他のスマートフォンやPCとは自動で共有されません  
- 機種変更時にはデータは引き継がれません
