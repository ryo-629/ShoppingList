# 🛒 多機能お買い物・タスク管理リストアプリ

HTML・CSS・JavaScript を用いて作成した、  
**スマートフォンでの使いやすさを追求した多機能リスト管理アプリ**です。

GitHub Pages を利用して公開しており、  
iPhoneやAndroidでは「ホーム画面に追加」することで、まるでネイティブアプリ（PWA風）のような快適さで使用できます。

---

## 📱 主な機能

### 1. 柔軟なリスト作成
- **タイトル入力**: お店の名前だけでなく、旅行の持ち物やTODOなど、用途に合わせた自由なタイトルを設定可能。
- **日付の出し分け（オン/オフ切替）**: チェックを入れたときだけ日付入力欄（カレンダー）が表示されるスマートなUI。
- **金額記録のオン/オフ切替**: 
  - **金額ありリスト**: 商品ごとの価格入力欄と、リスト全体の「合計金額の自動計算」を表示。
  - **金額なしリスト**: 商品名だけのシンプルなチェックリスト。価格欄や合計表示が消え、入力欄が横いっぱいに広がってスッキリ使えます。

### 2. 直感的なアイテム・リスト管理
- **チェックボックス管理**: 購入完了（またはタスク完了）した項目は、ワンタップで打ち消し線が入り一目で判別可能。
- **一括削除・個別削除**: 「チェック済みアイテムのみ一括削除」や「リスト全体の削除」が可能（誤操作防止の確認ダイアログあり）。

### 3. 快適なデザインと操作性
- **ダークモード対応**: 画面右上のボタンから、夜間や暗い場所でも目に優しいダークモードにワンタップで切り替え可能。
- **クッキリ見やすいチェックボックス**: ダークモードでも背景に馴染み、チェック時には太線の「✓」がハッキリ浮かび上がるカスタムデザイン。
- **スマートフォン・PC 両対応**: レスポンシブデザインで、どの端末からでも最適なレイアウトで表示。
- **オフライン・永続対応**: データの保存には `localStorage` を使用しているため、アプリを閉じたりオフラインになったりしても、入力したデータは消えずに残ります。

- HTML5

## 📲 スマートフォンでの使い方（推奨）

### iPhone（Safari）の場合
1. Safariで上記URLを開く  
2. 画面下の「共有」ボタンをタップ  
3. 「ホーム画面に追加」を選択  
4. ホーム画面に生成されたアイコンから起動

### Android（Chrome）の場合
1. Chromeで上記URLを開く
2. 右上のメニュー（三点リーダー）をタップ
3. 「ホーム画面に追加」または「アプリをインストール」を選択

※ App Store や Google Play を介さず、すぐにネイティブアプリ感覚で利用可能です。

---

## ⚠️ 注意点

- データは **端末ごと（ブラウザごと）に保存** されます。
- 他のスマートフォンやPCとは自動で同期・共有されません。
- ブラウザのキャッシュや履歴を完全に削除すると、保存されたリストが消去される場合があります。
- 機種変更時にはデータは引き継がれません。

## 📝 補足

本アプリケーションはフロントエンド（HTML/CSS/JS）のスキルアップおよび実用的なツールの自作を目的として作成したものです。サーバーサイド処理やユーザー認証機能を持たないため、個人データを外部に送信することなく安心・安全に動作します。
